# 📝 Online Quiz System

A simple and user-friendly **Online Quiz System** developed using **PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap**. This project allows administrators to manage quizzes and students to participate in online quizzes with instant results.

---

## 🚀 Features

### 👨‍💼 Admin
- Admin Login
- Dashboard
- Manage Subjects
- Manage Quizzes
- Add/Edit/Delete Questions
- View Results
- Manage Students

### 👨‍🎓 Student
- Student Login
- Dashboard
- Take Quiz
- Instant Result
- View Previous Results
- Profile Management

---

# 💻 Installation Guide

## Step 1

Download and install **XAMPP**.

---

## Step 2

Clone this repository or download the ZIP file.

```
git clone https://github.com/YOUR_USERNAME/online-quiz-system.git
```

Or download the ZIP and extract it.

---

## Step 3

Copy the project folder to:

```
C:\xampp\htdocs\
```

Example

```
C:\xampp\htdocs\online-quiz-system
```

---

## Step 4

Open **XAMPP Control Panel**

Start:

- Apache
- MySQL

---

## Step 5

Open phpMyAdmin

```
http://localhost/phpmyadmin
```

Create a new database named

```
online_quiz_db
```

---

## Step 6

Click **Import**

Choose

```
online_quiz_db.sql
```

Click **Import**.

---

## Step 7

Run the project

```
http://localhost/online-quiz-system
```
